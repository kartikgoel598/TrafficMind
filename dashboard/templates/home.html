About the Project

TrafficMind is a reproducible research platform for studying how reward function design affects the behavior of a reinforcement learning traffic signal controller. The agent learns from live queue length and waiting time data generated by a SUMO simulation and develops its own signal control policy without relying on predefined traffic rules. While previous research has shown that reinforcement learning can outperform fixed-time traffic signals, the effect of reward design is less well understood. This project isolates that factor by keeping everything else the same and changing only the reward function, allowing its impact on traffic efficiency, learning stability, and fairness to be evaluated directly.

While prior work shows RL can outperform fixed-time signals, it remains unclear how different reward formulations affect efficiency, stability, and fairness in practice. This project isolates that variable: everything else stays identical, only the reward changes.

Key Goals
01
Compare RL-based control against fixed-time and heuristic baselines across multiple traffic scenarios.
02
Isolate the effect of reward design on outcomes — efficiency, phase stability, and queue fairness.
03
Keep the system fully reproducible: fixed seeds, open-source simulation, and logged metrics at every step.
04
Provide a live dashboard for side-by-side policy evaluation without touching any code.
