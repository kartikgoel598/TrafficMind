# TrafficMind
A deep reinforcement learning–based traffic signal system using SUMO compares three reward functions: local intersection performance, network-wide coordination, and fairness between directions. The goal is to understand how reward design shapes learning and provide clear, evidence-based guidelines for better traffic control.

# Installation
SUMO needs to be installed to run this simulation, via https://sumo.dlr.de/docs/Installing/index.html select "Download 64-bit zip: sumo-win64-1.26.0.zip"

in main.py change the directory in SUMO_HOME variable to the place you have downloaded SUMO
for example SUMO_HOME = r"D:\Users\270487801\Downloads\sumo-win64-1.26.0\sumo-1.26.0"
